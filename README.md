## About

This project demonstrates how Go can efficiently manage concurrent network operations using goroutines and synchronization primitives.

It is intended for:

- Learning Go concurrency
- Studying HTTP client behavior
- Understanding worker pools
- Experimenting in controlled lab environments
- Educational purposes

## Installation

Clone the repository:

```bash
git clone https://github.com/strangered53/Redteaming.git
cd Redteaming
```

Build:

```bash
go build ddos.go
```

Run:

```bash
go run ddos.go
```
